# Эксплуатация

«Волга» разворачивается и сопровождается как единая production-система.

## Runtime

- FastAPI и фоновые workers;
- административный Next.js frontend;
- Privacy Gateway;
- service bot;
- nginx;
- PostgreSQL и Redis;
- задачи миграции и backup.

Физическая топология, адреса и характеристики серверов остаются закрытыми.

## Релиз

1. GitHub Actions собирает версионированные контейнерные образы.
2. Миграции выполняются отдельной задачей.
3. Новая версия проходит readiness-проверку.
4. Неуспешный запуск возвращает предыдущее приложение.

Откат приложения отделён от отката схемы данных: миграции проектируются с учётом совместимости соседних версий.

## Восстановление

PostgreSQL автоматически архивируется в закрытое объектное хранилище. Контролируется давность копии, а отдельная restore-процедура позволяет проверить восстановление в изолированную базу.

Публичный кейс не содержит domains, IP, registry paths, bucket names, credentials и production metrics.
