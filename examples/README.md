# Синтетические архитектурные примеры

Эти примеры я написал с нуля для публичного кейса. Они намеренно неполные и не содержат production-код.

- [channel_contract.py](channel_contract.py) — единый контракт события и интерфейс адаптера канала.
- [transactional_delivery.py](transactional_delivery.py) — атомарное сохранение сообщения и задачи доставки.
- [fail_closed_privacy.py](fail_closed_privacy.py) — запрет внешней обработки при ошибке очистки текста.
- [quota_guard.py](quota_guard.py) — резервирование, подтверждение и возврат AI-квоты.

Примеры показывают границы ответственности и инварианты, но не воспроизводят закрытую реализацию продукта.
